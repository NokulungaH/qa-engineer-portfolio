# Senior QA Evidence

This section demonstrates senior-level QA thinking through original, anonymized portfolio artefacts.

## Confidentiality statement
The case study is inspired by Nokulunga Hlongwa's experience establishing formal QA practices, but the product, people, data, risks, defects, metrics and scenarios below are fictionalized for demonstration. No employer/client system, production data, internal document or confidential incident is reproduced.

## Evidence set
- **QA Process Implementation Case Study** — how to introduce quality practices where formal QA is limited.
- **Test Strategy** — scope, test levels, environments, entry/exit criteria, risk and release approach.
- **Risk Register** — prioritization using likelihood × impact.
- **Requirement Traceability Matrix** — requirements mapped to risks and test coverage.
- **Exploratory Testing Charters** — time-boxed investigation missions.
- **Defect Reports** — realistic fictional examples with evidence expectations and severity/priority reasoning.
- **Release Readiness Checklist** — evidence-based go/no-go inputs.
- **QA Metrics** — useful measures with interpretation guardrails.

The purpose is not to suggest that one template fits every team. A senior QA approach should be adapted to product risk, team maturity, delivery model and available evidence.
