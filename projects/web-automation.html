PROJECT 01 · PLAYWRIGHT + TYPESCRIPT

FRAMEWORK BUILT

Web Automation Framework

A maintainable end-to-end automation framework against SauceDemo, designed to show test architecture, risk-based coverage and engineering practices rather than isolated scripts.

PlaywrightTypeScriptPage ObjectsFixturesSmokeRegressionCross-browser

What is automated

Successful authentication, locked-user rejection, required-field validation, product sorting, cart validation and a complete checkout journey.

Framework design

UI interactions are isolated in Page Objects, reusable objects are supplied through Playwright fixtures, test data is separated from test logic, and smoke/regression tags support purposeful suite selection.

Failure evidence

The framework retains traces, screenshots and video on failures and produces Playwright HTML reports, making failures easier to investigate rather than simply rerun.

Cross-browser strategy

Projects are configured for Chromium, Firefox and WebKit. Business-critical smoke scenarios are separated from broader regression coverage to support faster feedback.

Senior QA rationale

The goal is not maximum test count. The automated layer protects stable, repeatable, high-value user journeys while leaving exploratory investigation and rapidly changing behaviour to the appropriate testing approach.
