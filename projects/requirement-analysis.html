PROJECT 05 · TEST ANALYSIS

Requirement → Test Strategy

Test analysis

Requirement

Users should be able to reset their password.

Questions

How is the user identified? Does the link expire? Can it be reused? What happens for unknown email addresses? What password rules apply? What happens after multiple reset requests?

Risk areas

Account security, link expiry, session handling, password validation, error handling, rate limiting and usability.

Output

The final version will turn the requirement into test conditions, scenarios, negative cases, boundary cases and automation candidates.

Senior QA angle

Good test design starts before execution. Ambiguous requirements are a quality risk and should be challenged early.
