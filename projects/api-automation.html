8/8 CI TESTS PASSING

API Automation

A service-level Playwright + TypeScript suite against JSONPlaceholder demonstrating response-contract validation, CRUD-style workflows, negative paths and data-integrity assertions.

Playwright APITypeScriptGET / POST / PUT / DELETENegative TestingContract ChecksCI

Verified coverage

Eight automated tests cover existing-resource retrieval, collections, create/update/delete responses, an unknown-resource 404, nested user data and query-filter integrity.

Beyond status codes

Assertions validate JSON media type, object shape, field types, nested structures, returned values and filtering behaviour rather than treating a 2xx response as sufficient evidence.

Framework design

A reusable API client centralizes HTTP operations and shared checks. Fixtures supply the client to tests, test data is separated from behaviour, and smoke/regression tags support targeted execution.

API behaviour awareness

JSONPlaceholder simulates write operations, so the suite validates the returned create/update/delete behaviour without incorrectly expecting those changes to persist on the public service.

Execution evidence

The GitHub Actions pipeline completed successfully with 8/8 tests passing in 1.2 seconds and generated a Playwright HTML report artifact.
